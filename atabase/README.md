# Smart Loyalty Point System (ระบบสะสมแต้มซื้อสินค้า)
รายวิชา COMP342 วิศวกรรมซอฟต์แวร์เบื้องต้น

## 👥 สมาชิกในทีมและการแบ่งโมดูล (Team Modules)
1. **Project Manager & System Analyst**
   - รับผิดชอบ: วิเคราะห์ระบบ, จัดทำเอกสาร SRS และออกแบบโครงสร้างฐานข้อมูล (`database/schema.sql`)
2. **UI/UX Designer & QA**
   - รับผิดชอบ: ออกแบบหน้าจอการใช้งาน และทดสอบระบบ (Test Case)
3. **Full Stack Developer**
   - รับผิดชอบ: พัฒนาระบบหลังบ้าน (`backend/`) และระบบคำนวณแต้มอัตโนมัติ

## 🛠️ Tech Stack
* **Database:** MySQL (phpMyAdmin)
* **Backend:** PHP
* **Frontend:** HTML, CSS, JavaScript
*  อัปเดตล่าสุดเรียบร้อย
